# 行動実行の観測・予測・再計画

`agent/execution_evidence.py` は ARC-AGI-3 の盤面と行動の対応を扱うゲーム固有層です。
汎用 EDD や ADK スキルのロード処理は追加していません。

## 行動後の検証

- 画面差分、物体移動の予測一致、レベル進捗を別々に記録します。
- 同じ色の画素集合が一意に平行移動した観測を同じボタンで2回確認してから、方向と移動量を採用します。
- リセット・クリック・レベル遷移を移動方向の学習に使いません。
- 1〜2ピクセルの説明できない変化は不確実な観測として扱います。HUDと断定せず、再探索や長い計画継続を正当化する進捗にも使いません。
- 予測不一致、状態の反復、レベル進行で実行キューを破棄します。

## 計画と操作

- 自機候補の色と検証した移動物体の色が一致し、移動量が1画素の場合のみ、自動幾何計画を使います。複数画素の物体はこの自動計画の対象外です。
- 自動計画は最大3手です。実際の初手が計画の初手と一致し、移動予測を設定できた場合のみ、残り最大2手をキューへ登録します。
- 次の高速実行には直前の移動予測の成立が必要です。
- 対象候補は未検証の探索先として扱い、ゴールと断定しません。固定の色番号を壁と決め付けず、他の占有色を保守的に避けます。
- 確認前のボタンには方向ラベルを付けません。本番の自律プローブでは未確認ボタンを分散して試します。
- 確定した操作は `GameActionTools` の Level 3 ツールを経由します。

## クリック試行とリセット

クリック試行は状態ごとの座標集合に保存します。変化がない状態では未試行のアンカーを優先し、同じ失敗を繰り返さないようにします。微小な不確実変化だけでは試行記憶を解除しません。盤面が明確に変化した場合やレベルが進んだ場合は同じ座標を再評価できます。通常のリセットでは試行知識を保持し、ゲーム間では分離します。

アンカー候補がない場合は未試行の画素を探索します。全候補を試した場合の完全な解法や、罠の安全性を保証する仕組みではありません。試行状態の保持は256件に制限しています。

## 推論と計測

盤面・利用可能ボタン・カーソル位置が同一の場合、視覚要約を最大2回再利用します。予測不一致やリセットでは再観測し、計画と行動の推論は省略しません。前回の状態遷移の証拠は各回のプロンプトに別途渡します。

`reasoning` に以下を記録します。

- `previous_transition`: 前の行動の画面差分・予測一致・レベル進捗・再訪判定
- `prediction_armed`: 今回の行動に具体的な物体移動予測があるか
- `phase_metrics`: 観測・計画・行動の所要時間、視覚要約の再利用
- `trial_state_id`, `click_target_grounded`, `repeated_click_trial`: 試行と対象候補の情報

ローカル評価器は行動後に `execution_outcome` を記録します。これは今回の行動の結果です。履歴には予測の検証件数・一致率、レベル進行手数、視覚要約再利用回数、同じ状態のクリック再試行数も保存します。既存の画面変化率は意味を変更せず残しています。

## 検証の限界

物体追跡は一意な同色画素集合の平行移動に限定しています。複数の同色物体、アニメーション、大きなHUD変化、見た目が同じ隠れ状態については追加の認識が必要です。目標の意味やゲーム固有ルールを完全に推論する実装ではありません。スコア改善は実モデルの同条件再評価で確認する必要があります。
