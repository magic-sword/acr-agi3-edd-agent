### 中核となる発見 (Core Insights)
1. **初期数秒の「何もしない時間（Visual Inspection Pause）」が勝敗を分ける**: 人間は環境開始直後（0〜6秒）、キー入力を一切行わず、ターゲット表示（目標状態）と現在配置（初期状態）の空間的ゲシュタルト（色、配置、幾何学的対称性）の差分を抽出し、操作可能候補（アフォーダンス）を特定している。
2. **認識論的行動（Epistemic Action）の明確な先行**: ゴールを直接目指す実利的行動に先立ち、「可動域の確認」「連動性の確認」「保持特性の確認」といった**環境ルール同定のための純粋な実験手**を実行している。
3. **完成図からの逆算（Backward Chaining）と退避バッファの創出**: 障害物や制約がある場合、順方向に場当たり的に進めるのではなく、「最終状態の1手前」から逆算し、途中で「一時的な待避場所（Staging / Buffer Area）」を意図的に利用して順序入れ替えを行う。
4. **失敗時の戦略的リセットと禁忌（No-Go）の獲得**: 失敗した際、人間は闇雲に手を戻すのではなく、「この配置はデッドロックを引き起こす」という禁止制約を瞬時に学習し、能動的リセット（Active Reset）を行って探索空間を剪定（Pruning）する。

### 次元 2: 階層的ゴール分解能と逆算プランニング (Hierarchical Subgoal Decomposition)

人間の問題解決の最大の特徴は、**「大目標（Target Pattern）から逆算して、先行して解決すべきサブゴールを順序立てる能力（Backward Chaining）」**と**「中間バッファ領域（Staging Area）の自律的創出」**にあります。

```
【人間の階層的サブゴール分解フロー】
[最終大目標: 赤・橙・青・緑 の水平整列]
       │
       ▼ (逆算: 最終端となる緑を最後に接合するため、まず赤・橙・青の3連を左に寄せる)
[サブゴール 1: 障害物・不要ブロックの一時退避]
  - 混ざっている青・緑を一時的に下段レールへ逃がす（バッファ利用）
       │
       ▼ (依存解決: 退避によりフリーになった赤を掴む)
[サブゴール 2: 先頭ブロック（赤）の基準位置への固定]
       │
       ▼ (部分構造のインクリメンタルな構築)
[サブゴール 3: 橙を赤の右隣に接合 → 赤・橙ペアの完成]
       │
       ▼ (順次追加)
[サブゴール 4: 退避させていた青を回収・結合 → 赤・橙・青トリオの完成]
       │
       ▼ (終局)
[サブゴール 5: 最下段の緑と水平アラインメントを合わせて完成]
```

#### 実際の記録に見る人間の思考パターン
> * **`sk48` (Level 2, [00:36–01:03])**:
>   * *「ターゲットは赤→橙→青→緑。初期状態は緑→青→橙→赤（完全逆順）。ブロックを単に右にスライドさせるだけでは解決できず、並べ替え（Reordering）が必須。」*
>   * *「[00:51] 赤を左端に確保する間、橙は右側に一時隔離し、青と緑が下段に退避されることを許容する（Preserve progress while accepting temporary displacement of other pieces）。」*
> * **`sample_vcgt_002`**:
>   * *「扉がゴールへの道を完全に塞いでいる。鍵を取らずに扉に向かうとデッドエンド。鍵の取得（Precondition）が厳密な前提条件である。」*

#### 特筆すべき認知的発見: 「一時的悪化（Detour / Staging）」の受容
強化学習エージェントは「ゴールまでの距離（ヒューリスティック関数）」が単調減少することを好むため、ブロックを一時的にゴールから遠ざけたり、順序を崩してバッファに置く手（Hill Climbing の谷を越える手）を打つことが極めて困難です。
しかし人間は、**「一時的に他のピースが散らばることを許容しながら、キーストーン（赤ブロック等）を確定させる」**という高次プランニングを自然に行っています。

#### 認識論的行動比率 (Epistemic Action Ratio: EAR) の分析
* 新しい要素（新オブジェクト、新ピストン、新障害物）が登場した直後の手番において、**EAR は 70% 以上** に達します。
* **最小介入の原則 (Isolation of Variables)**: 人間はすべてのキーを連打するのではなく、「ピストンを上へ1回伸ばす」「1つのブロックだけに当てる」というように、原因と結果（因果関係）が1対1で対応する最小単位の介入を行います。

### 次元 4: 失敗帰因と禁忌制約学習能 (Failure Attribution & Constraint Learning)

人間は失敗した際、それを単なるマイナス報酬として処理するのではなく、**「なぜ失敗したのかの因果帰因（Attribution）」を行い、瞬時に「禁忌ルール（No-Go Constraints）」として知識化**します。

#### 実際の記録に見る人間の思考パターン
> * **`sk48` (Level 4, [02:29–02:33])**:
>   * *「ブロックを一括で運ぼうとした試行が目標と合致しないと確認した時点で、試行を中止してリセット（Reset）し、全4ブロックを初期位置へ戻した。」*
>   * *「[02:33] 失敗した試行から『ブロックをまとめて動かすのではなく、制御された順序で配置しなければならない』という制約を学習し、シアン側ピストンへ青を個別に運ぶ戦略へ切り替えた。」*
> * **`sk48` (Level 5, [00:04:20])**:
>   * *「青ブロック3連を下段ルートから一括で通そうとしたが、赤ブロックと交互に挟むことができないと判明。失敗した構成を破棄し、上段ルートと下段ルートの両方に分割して通すアプローチに変更した。」*

#### 能動的リセット（Active Reset）の意義
* 人間は「袋小路（デッドロック）」に陥った際、無理に修復しようとして泥沼化することを避け、**「能動的リセット」を選択して初期状態から正しい手順を再実行**します。
* これは「状態空間の修復コスト」と「ゼロからの再現コスト」を天秤にかけ、後者の方が確実であると判断するメタ認知（Metacognition）の現れです。

### 次元 5: 認知柔軟性とマクロスキル転移 (Cognitive Flexibility & Skill Transfer)

ゲームが進行してレベルが上がる（Level 1 → Level 8）につれて、盤面の障害物やピストン数が増加しますが、人間は以前のレベルで獲得した操作パターンを**「マクロスキル（定石）」**として再利用します。

```
【人間が蓄積・転移するマクロスキルの例】
1. "Isolate-and-Stage" (隔離・待避スキル):
   - 目的ブロックに干渉する隣接ピースを一時的に安全な空きスペースへ退避させる。
2. "Pair-and-Carry" (結合・運搬スキル):
   - すでに順序が正しい2ブロック（赤・橙）を1つの剛体として扱い、同時に移動させる。
3. "Lane-Splitting" (レーン分割スキル):
   - 交互配列（赤・青・赤）を作るため、一方の色を上レーン、他方を下レーンへ迂回させて合流させる。
4. "Shared-Center Cross Assembly" (共通中心交差スキル):
   - 水平アームと垂直アームの交点となる共通ピース（緑）を基準点（アンカー）として固定する。
```

#### 機能的固着（Functional Fixedness）の打破
* 単一の解法パターン（例：「下段ルートから回り込む」）が黒い障害物ブロックで塞がれた場合、人間は即座に視点を変え、「上段ルートと下段ルートに分散させる」という新しい幾何的経路を見出しています。

## 4. 人間の課題解決アーキタイプ分類 (Taxonomy of Cognitive Archetypes)

ACR-AGI-3 の各種環境において観測された人間の適応スタイルは、以下の4つのアーキタイプに大別されます。

```
┌─────────────────────────────────────────────────────────────┐
│                 人間問題解決の 4 大アーキタイプ                     │
├──────────────────────────────┬──────────────────────────────┤
│ 1. 逆算建築家 (The Backward Architect) │ 2. 探針科学者 (The Probing Scientist) │
│    - 代表環境: sk48 (ブロック・ピストン)   │    - 代表環境: bp35, m0r0 (連動・対称)│
│    - 思考: 完成図から逆算、バッファ確保 │    - 思考: 最小介入で未知力学を解明    │
├──────────────────────────────┼──────────────────────────────┤
│ 3. 因果プログラマー (The Causal Coder) │ 4. 動的ナビゲーター (The Risk Navigator)│
│    - 代表環境: tn36, vcgt_002 (記号/鍵)│    - 代表環境: tu93 (迷路・回避)     │
│    - 思考: 依存順序の記述とデバッグ     │    - 思考: 空間トポロジーと境界把握     │
└──────────────────────────────┴──────────────────────────────┘
```

1. **逆算建築家 (The Backward Architect - `sk48`)**:
   * ゴールパターンと初期パターンの「差分（順序の逆転、相対位置）」を特定し、キーストーンとなるブロックを定めてから、残りを待避・合流させる。
2. **探針科学者 (The Probing Scientist - `bp35`, `m0r0`)**:
   * 操作と環境反応のルールが不明瞭な際、1手だけ動かして画面全体の差分（どのブロックが連動したか、対称移動したか）を検知し、因果モデルを構築する。
3. **因果プログラマー (The Causal Programmer - `tn36`, `sample_vcgt_002`)**:
   * 「Aを実行するとBが開く」「記号Xは右移動」といった決定論的ルールを同定し、 precondition → action → effect のチェーンを組み立てる。
4. **動的ナビゲーター (The Risk Navigator - `tu93`)**:
   * 迷路の通路（Corridor）と壁（Wall）を視覚的に分離し、死角やトラップを回避しながら最短経路を維持する。

## 5. エージェント・メタスキル基盤（`meta_skills/`）への実装還元指針

人間の適応プロセスの解析から得られた知見を、本リポジトリのメタスキル群（Google ADK 2.0 準拠 Progressive Disclosure アーキテクチャ）へ以下のように落とし込みます。

### 1. `meta_skills/env-observer/` への還元
* **初期休止＆ゲシュタルト抽出プロトコルの追加**:
  * 最初からアクションを生成させず、ステップ0では必ず「ターゲット表示」「現在盤面」「可動オブジェクト」「対称性」の抽出のみを行わせる（人間における `[00:00–00:06]` の Visual Inspection の模倣）。
* **差分検出器の組み込み**:
  * 目標シーケンスと初期配置の順序差分（例:「赤-緑-青」対「赤-青-緑」）を自動計算し、必要な操作種別（単純スライド vs 入れ替え待避）を分類。

### 2. `meta_skills/subgoal-decomposer/` への還元
* **逆算プランニング（Backward Chaining）ヒューリスティクス**:
  * サブゴール生成時、「最終的に固定すべき位置」から逆順に依存関係を組み立てる。
* **一時的バッファ（Staging Space）の認識**:
  * サブゴールの中に「目的外ブロックの一時待避」を正当な中間状態として明示的に許容する。

### 3. `meta_skills/constraint-learner/` への還元
* **デッドロック・No-Go 制約の即時登録**:
  * 手詰まり（ブロックが壁に挟まれて動かなくなった、同じ状態が3ループした）が発生した際、その直前の配置を「進入禁止・配置禁止状態」として記憶し、後続の探索から剪定。
* **戦略的リセットのトリガー条件**:
  * 修復にかかる推定手数が初期化からの再実行手数を上回った場合、能動的にリセットアクションを選択させる。

### 4. `meta_skills/contract-tester/` への還元
* **認識論的行動テスト（Epistemic Probing Contract）**:
  * 生成されたスキルの実行前に、「ピストンの有効範囲」「壁の衝突判定」を1ステップで検証する正例・負例テストを自動合成する。

## 6. まとめ

人間が ACR-AGI-3 の未知環境に即座に適応できる本質は、**「優れた視覚事前知識（ゲシュタルト）に基づく初期仮説」「ルール同定のための認識論的実験」「完成図からの逆算とバッファ利用」「失敗からの禁忌制約獲得」**が有機的に連携している点にあります。

本解析結果を各メタスキルのプロンプトおよび評価ゲート（EDD）の設計基準とすることで、エージェントは単なるブルートフォース探索から脱却し、人間と同等の洗練されたサンプル効率で未知ゲームを攻略することが可能になります。
