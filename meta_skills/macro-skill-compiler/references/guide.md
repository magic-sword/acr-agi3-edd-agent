# Macro Skill Compiler Reference Guide

## 1. Human Problem-Solving Archetypes
In ACR-AGI-3 gameplay records, human solvers naturally group repeated low-level actions into conceptual macro skills:
1. **Isolate-and-Stage**: Moving an obstacle to an open siding.
2. **Pair-and-Carry**: Once blocks A and B are connected, moving them as a single rigid body.
3. **Lane-Splitting**: Using dual bypass routes to interleave alternating colors.
4. **Anchor-Cross**: Building outward from a central intersection node.
