# Epistemic Prober Reference Guide

## 1. Epistemic Action vs Pragmatic Action
In cognitive science (Kirsh & Maglio 1994), an action is:
- **Pragmatic**: Directly advances towards the primary reward or terminal goal state.
- **Epistemic**: Modifies the mental state / knowledge of the agent by revealing hidden environmental variables.

## 2. Minimal Intervention Principle (Isolation of Variables)
When probing an unfamiliar puzzle mechanic (such as how a piston extends or whether blocks stick together), execute exactly ONE primitive action, pause, and compute the resulting image difference before chaining further steps.
